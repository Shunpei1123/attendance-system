# 出席管理システム

個人に番号を割り当て、キーボードから数字を入力すると個人名と時刻をHTMLファイルに保存・管理できるシステムです。

## 機能

- 🔢 **個人番号入力**: キーボードから数字を入力して出席を記録
- 📊 **出席記録表示**: リアルタイムで出席記録をリスト表示
- 💾 **HTML保存**: 出席記録をHTMLファイルでダウンロード保存
- 🖨️ **印刷機能**: 保存したHTMLファイルから印刷可能
- 🗑️ **レコード管理**: 個別削除またはすべてクリア機能

## セットアップ

### 1. 個人データの設定

`people.json` ファイルを編集して、個人番号と名前をマッピングします：

```json
{
  "1": "田中太郎",
  "2": "佐藤花子",
  "3": "鈴木次郎",
  ...
}
```

または、`index.html` の JavaScript セクション内の `people` オブジェクトを直接編集：

```javascript
const people = {
    1: '田中太郎',
    2: '佐藤花子',
    ...
};
```

### 2. サーバーの起動

```bash
npm start
```

または

```bash
node server.js
```

### 3. ブラウザでアクセス

ブラウザで以下のURLにアクセス：
```
http://localhost:3000
```

## 使い方

1. **番号入力**: テキストボックスに個人番号を入力
2. **出席記録**: 
   - 「出席記録」ボタンをクリック、または
   - Enterキーを押す
3. **確認**: 個人名と時刻がリストに追加されます
4. **保存**: 「HTMLで保存」ボタンをクリックしてHTMLファイルをダウンロード
5. **管理**: 
   - 記録の削除：「削除」ボタン
   - 全記録削除：「すべてをクリア」ボタン

## ファイル構成

- `index.html` - メインのWebインターフェース
- `people.json` - 個人番号と名前のマッピング
- `server.js` - Node.js サーバー
- `package.json` - プロジェクト設定

## 技術スタック

- **フロントエンド**: HTML5, CSS3, JavaScript
- **バックエンド**: Node.js
- **データ保存**: ブラウザのローカルストレージ

✅ シンプルで使いやすいUI
